# Chemistry and materials science domain profile

This profile captures figure conventions for synthesis, catalysis, materials characterization, and performance studies.

## Key principles

- Report yields, conditions, and replicate synthesis runs explicitly.
- Define error bars as SD, SEM, or CI.
- Link structural characterization to performance claims.
- Avoid unsupported mechanistic arrows.

## Preferred families

- `comparison_effect` for performance metrics.
- `trend_trajectory` for kinetics and cycling.
- `mechanism_architecture` for reaction schemes.
- `matrix_array` for spectra or diffraction grids.
- `spatial_image` for microscopy.
