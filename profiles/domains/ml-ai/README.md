# Machine Learning and AI domain profile

This profile captures figure conventions for ML/AI papers.

## Key principles

- Show seed uncertainty and replication.
- Separate benchmark ranking from calibration and ablation claims.
- One controlled change per ablation panel.
- Avoid radar charts for benchmark comparison.

## Preferred families

- `comparison_effect` for metric comparisons.
- `classification_diagnostics` for model evaluation.
- `optimization_sensitivity` for ablations and scaling laws.
- `trend_trajectory` for learning curves.
- `matrix_array` for confusion matrices.
- `relationship_embedding` for latent-space visualizations.

## Reporting standards

- TRIPOD+AI when reporting prediction models.
- ML reproducibility checklist for benchmark claims.
