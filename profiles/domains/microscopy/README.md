# Microscopy and imaging domain profile

This profile captures figure conventions for microscopy and imaging-heavy domains.

## Key principles

- Every image panel needs a calibrated, editable scale bar.
- Pair images with quantitative companion panels.
- Disclose cropping, field selection, and intensity normalization.
- Keep segmentation overlays semantically explicit.

## Preferred families

- `spatial_image` for image panels.
- `image_quantitative_composite` for image + quantification.
- `comparison_effect` for measurement comparisons.
- `mechanism_architecture` for model or pathway schematics.

## Reporting standards

- REMBI for bioimaging experiments.
