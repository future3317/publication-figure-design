# Genomics and omics domain profile

This profile captures figure conventions for genomics, transcriptomics, proteomics, and related omics studies.

## Key principles

- Show the full tested population, not only significant hits.
- Declare normalization, multiplicity correction, and threshold.
- Link enrichment results to gene-set size and adjusted p-values.

## Preferred families

- `statistical_discovery` for volcano, MA, Manhattan plots.
- `matrix_array` for heatmaps and correlation matrices.
- `relationship_embedding` for PCA/UMAP/t-SNE.
- `comparison_effect` for differential expression.

## Reporting standards

- MINSEQE / MIAME for sequencing experiments.
- STREGA for genetic association studies.
